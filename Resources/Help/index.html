Epitome

Instant file-name search for your Mac. Epitome indexes the names of every file and folder on your disks, keeps the index current as files change, and shows matches while you type.

Click any example in these pages to run it in the front search window.

Searching

Type part of a name: invoice finds every item whose name contains “invoice”. Several words must all match, in any order: invoice 2026 pdf. Use | for “or”, ! for “not”, < > to group and quotes for exact text with spaces: "tax return" <pdf|docx> !draft.

A word containing a slash matches the full path: Projects/ swift finds Swift files in any folder called Projects. Functions narrow by other properties — ext:jpg;png size:>2mb dm:thisyear. The Search Syntax page lists everything.

The window

  • Filter bar (right of the search box) restricts results to Audio, Documents, Pictures and so on without changing what you typed. Edit filters with Search → Organize Filters.
  • Columns: right-click the header to show Extension, Type, dates, Attributes, Run Count and more; click a header to sort (dates and sizes start newest/largest first).
  • Views: Details or thumbnails (View menu); Preview (⌥⌘P) shows the selected file beside the list; Space opens Quick Look.
  • Status bar shows the result count, the selection’s size, and indicators such as CASE, PATH or REGEX for active options — double-click an indicator to turn it off.

The index

On first launch Epitome reads every included volume (Settings → Volumes). After that it follows changes through macOS file system events, and remembers where it left off, so changes made while Epitome wasn’t running are caught up at the next start. The index is saved to disk regularly and when you quit.

  • Full Disk Access (System Settings → Privacy & Security) lets Epitome include protected folders such as Mail and Messages data. Without it those folders are skipped.
  • Folders outside your volumes (for example network shares) and file lists (.efu) can be added in Settings.
  • Exclude hidden files, system files or any folders and file patterns you never want to see.
  • Tools → Index Journal lists recent changes (created, deleted, renamed, modified); Tools → Indexes → Statistics shows what is indexed.

Filters, bookmarks and history

Filters are saved searches combined with whatever you type; each can have a macro — audio: live — and a shortcut. Bookmarks (⌘D) restore a whole search: text, options, filter, sort and view. Search history (off by default, Settings → History) suggests earlier searches when you press ⌥Esc in the search box; run history counts how often you open items from Epitome — sort by Run Count or search runcount:>5.

File lists

A file list (.efu, a CSV of paths, sizes, dates and attributes) is a snapshot you can search later or on another Mac — for example of an external drive that isn’t connected. Create one with Tools → Create File List from Folder, File → Export (choose EFU), or the File List Editor; open one with File → Open File List (⌘O).

Searching other computers

Turn on the HTTP server to search this Mac from any browser, or the ETP/FTP server so another copy of Epitome can connect with Tools → Connect to ETP Server. Both can require a user name and password and can be limited to certain network interfaces.

Search commands

Typed into the search box and run with Return: >rebuild (rebuild the index), >update or >update ~/Folder (rescan), >pause / >resume (monitoring), >save-db, >new-window, >close, >closeall, >quit, >restart, >debug, >options, >config_save, >config_load, about:, about:config, about:home. >setting shows a setting and >setting=value changes it (Tab completes names) — for example >searchDelayMs=150.
