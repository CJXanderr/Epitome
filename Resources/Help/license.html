About Epitome

Instant file-name search for macOS.

Epitome is a clean-room implementation of the feature set of Everything by voidtools: it was written from public user documentation describing how that Windows search tool behaves, without access to its source code. Epitome is not affiliated with or endorsed by voidtools; product names are used only to describe compatibility.
