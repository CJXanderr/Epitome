Search Syntax

Plain words match anywhere in a name, ignoring case and accents. Everything below refines that.

Operators

TypeMeaningExample
spaceAND — every term must matchreport 2026
|ORjpg|png
!NOT — exclude the next term or groupreadme !.md
< >Group<draft|final> proposal
" "Exact text, including spaces and symbols"meeting notes"
( )Group (when allowed in Settings → Search)(a|b) c
AND OR NOTWord operators (when allowed in Settings → Search)cats OR dogs

OR binds tighter than AND: apple banana|orange means apple AND (banana OR orange). Settings → Search can switch the precedence.

Wildcards

WildcardMatchesExample
*Any characters within one name (not across /)*.mp3
**Any characters, across folders~/Code/**/README*
?One characterIMG_????.HEIC

A term with a wildcard must match the whole name: report* finds names that start with “report”, *report* names that contain it. A term without wildcards is always a substring match.

Paths

A term containing a slash matches the full path instead of the name. A trailing slash means “inside this folder”:

SearchFinds
~/Downloads/everything in Downloads and its subfolders
Downloads/ pdfPDFs in any folder named Downloads (full path contains “Downloads/”, name contains “pdf”)
/Volumes/Backup/ !.DS_Storeeverything on a drive called Backup, except .DS_Store files
~/Pictures/*items directly inside Pictures (one level)
parent:~/Desktopitems directly inside the Desktop folder

Quote paths with spaces: "~/Library/Application Support/" log. Match Path (⌥⌘U) matches every term against the full path.

Modifiers

Put modifiers in front of a term or function; they stack: folder:case:Src.

ModifierEffect
case: nocase:Match case / ignore case
diacritics: nodiacritics:Match accents (é ≠ e) / ignore them
file: folder:Only files / only folders — alone they list all files or folders
path: nopath:Match the full path / only the name
ww: wholeword:Whole words only
wfn: exact:The whole name must equal the text
regex:The term is a regular expression
wildcards: nowildcards:Treat * and ? as wildcards / as plain characters
nohighlight:Don’t highlight this term in the results

Examples: folder:node_modules · case:README · ww:test · wfn:Makefile · path:ww:src

Functions

A function is written name:value. Numbers, sizes and dates take comparisons: = < <= > >= != and ranges a..b or a-b. Several values separated by ; mean any of them.

Sizes

A number is bytes; add kb, mb, gb or tb (powers of 1024 unless Settings → Search says otherwise). size:1mb on its own means “1 MB, rounded down” (1,048,576–2,097,151 bytes); comparisons use the exact value: size:>=100mb · size:10mb..50mb.

Dates

Write dates as 2026, 2026-03, 2026-03-14, 2026-03-14T09 … — each means the whole year, month, day or hour. Ranges run from the start of the first to the end of the second: dm:2025-07-01..2026-06-30. >2025 means after 2025 (from 1 January 2026).

KeywordMeaning

dm:thisweek thismonth thisyearThe current calendar week, month or year
dm:lastweek lastmonth lastyearThe previous complete calendar week, month or year
dm:past7days pastweekThe last 7 days up to now (rolling)
dm:last3months last2hours last10minsFrom that long ago until now and later
dm:3daysThe same as past3days
dm:3weeks..1weekBetween 3 weeks and 1 week ago

Macros

Every filter with a macro can be used inside a search: audio: zip: doc: exe: pic: video: — combine them like terms: <pic:|video:> dm:thisweek. Bookmarks can have macros too. Special characters: quot: apos: amp: lt: gt: and #x263A: for any Unicode character.
