Command Line

Two command-line entry points: ep searches the running index from Terminal, and the Epitome app itself accepts switches that open or control a search window.

ep — search from Terminal

Install it with Tools → Install Command Line Tool (it links /usr/local/bin/ep to the copy inside Epitome.app). Epitome must be running.

CommandDoes
ep report pdfPrint the full paths of matching items
ep -n 20 -sort size-descending ext:movThe 20 largest .mov files
ep -size -date-modified -csv dm:today > today.csvColumns of your choice, as CSV (also -tsv -json -efu -txt -m3u)
ep -path ~/Projects ext:swiftOnly results inside a folder (-parent: directly inside)
ep -case -ww -r '^IMG_\d+'Match case, whole words, a regular expression
ep -filter Audio liveUse a filter defined in the app
ep -get-result-count video:Just the number of results (-get-total-size: their total size)
ep -journal -from-todayIndex changes made today
ep -get-run-count FILE · -set-run-count FILE N · -inc-run-count FILERun history
ep -reindex · -save-db · -rescan-all · -exitIndex maintenance and quitting the app
ep -gui -search foo -filter AudioOpen a search window in the app
ep -save-settings … / -clear-settingsRemember options for future ep calls / forget them
ep -helpEvery option

Exit codes: 0 success, 4 bad argument, 5 the export file could not be written, 6 unknown switch, 7 the query failed, 8 Epitome isn’t running, 9 no results (with -no-result-error).

Epitome app switches

Run /Applications/Epitome.app/Contents/MacOS/Epitome [switches] or open -a Epitome --args [switches]. When Epitome is already running, the switches are passed to it.

SwitchEffect

-parent FOLDEROnly items directly inside

-filename FILEFind that file (a folder: its contents)
-name-part FILE · -stem FILE · -extension FILESame name / stem / extension
-search-file-list LIST.txtFind the names listed in a text file
-case -nocase -ww -noww -matchpath -nomatchpath -diacritics -nodiacritics -regex -noregexMatch options
-filter NAME · -bookmark NAME · -homeFilter, bookmark or the home search
-url epitome:...Open an epitome: link

epitome: links

epitome:SEARCH?key=value&…#FILE opens a window with that search; #FILE selects that result. Keys: sort=date-modified-descending, ascending=0|1, case, diacritics, path, regex, wholeword, filter=NAME, bookmark=NAME, view=details|thumbnails|PX, newwindow=1. Escape ? # and % as %3F %23 %25. Example: ext:pdf dm:thisweek.
